# Скрейпер
## Описание
Программа-скрейпер для сайта https://books.toscrape.com.

Программа обходит все страницы с книгами из заданного раздела (раздел задается урлом, с которого начинается обход).

Парсинг страниц осуществляется при помощи css-селекторов. Обход страниц проходит асинхронно.

## Запуск
Для запуска программы нужно:
1. Установить зависимости:
```
pip install -r requirements.txt
```

2. Запустить main.py:
```
python main.py
```

## Результат
Результат обхода сохраняется в корневой папке `result` в файле `result.jsonl`.
